# Customer Churn Analysis

## Project Overview

This project analyzes customer churn using Python and Pandas to identify factors associated with customer churn and high-risk customer segments.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Overall churn rate
- Churn by geography
- Churn by gender
- Churn by age group
- Churn by credit score
- Churn by tenure
- Churn by balance
- Churn by number of products
- Churn by active membership
- Correlation analysis
- High-risk customer segmentation

## Key Deliverables

- Churn rate by customer attributes
- Ranked churn-associated factors
- High-risk customer segments
- Five customer retention recommendations

## Conclusion

The analysis helps identify customer groups with higher churn risk and provides data-driven recommendations for improving customer retention.
